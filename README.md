# QMix 轻麦 · 免费直播路由混音台

[官方网站](https://qmix.top/) · [下载与系统要求](https://qmix.top/#downloads) · [连接指南](https://qmix.top/#hardware-setup) · [操作图解](https://qmix.top/#workflow)

QMix 轻麦是一款原生桌面直播路由混音台。把麦克风、声卡、应用声音与现场音效汇入同一个工作台，调节音量与人声效果，再按需送往耳机监听、声卡或直播软件，让每一路声音都有清楚的去向。

软件永久免费使用，全部内置功能免费，无广告，无需账号、订阅或激活。可选第三方插件遵循各自许可。

## 主要功能

- **矩阵混合与节点连接**：两种工作视图使用同一套混音配置，通过矩阵交点或节点连线安排声音去向。
- **多音源输入**：接入麦克风、声卡、应用声音和音效，按通道独立管理。
- **监听与直播分开控制**：同一输入可发送到多个输出组，每条发送独立调整音量与静音；输入效果链由该通道的发送共用。
- **七类内置人声效果**：降噪、自动增益、八段 EQ、压缩、去齿音、混响和限幅，配合可视化参数编辑。
- **VST3 插件扩展**：扫描插件目录，将已安装的第三方效果器加入输入效果链。兼容性依插件和平台而定。
- **智能调音与现场音效**：本地分析后提出调音建议，由用户确认；音效面板支持现场触发与独立试听。
- **悬浮控制与配置保存**：通过迷你控制条、快捷键管理常用操作，并导入、导出矩阵混合配置。
